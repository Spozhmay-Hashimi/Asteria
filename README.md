# 🌌 Asteria — Space Exploration Website

> **Explore Beyond. Discover More. 🚀**

**Asteria** is a modern and responsive space exploration website designed to introduce users to the fascinating world of space, missions, celestial objects, and astronomical discoveries.

The project combines a futuristic visual style with a clean and responsive interface to create an immersive space-themed experience.

---

## 🚀 Features

* 🌌 Modern and futuristic space-themed design
* 📱 Fully responsive layout
* 🪐 Space and astronomy content
* 🚀 Dedicated missions section
* 🌠 Interactive and visually engaging UI components
* 🧭 Easy navigation between different sections
* 💻 Optimized for desktop, tablet, and mobile screens

---

## 📄 Website Sections

Asteria is divided into four main sections:

* 🏠 **Home** — Introduction to Asteria and the universe
* 🪐 **Explore** — Planets, stars, galaxies, and celestial objects
* 🚀 **Missions** — Space missions, astronauts, and exploration
* 🌌 **Discover** — Astronomical events, constellations, and interesting facts

---

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **Bootstrap 5**

---

## 📱 Responsive Design

Asteria is designed to provide a smooth experience across different screen sizes, including:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

---

## 🎨 Design Concept

The visual identity of Asteria is inspired by **deep space, exploration, technology, and the mystery of the universe**.

The design uses dark cosmic backgrounds combined with purple, blue, and cyan accents to create a futuristic atmosphere.

---

## 👩‍💻 Project

This project was developed as a collaborative web development project, with each team member responsible for designing and developing a dedicated section of the website.
